# Federated Learning with Homomorphic Encryption

This repository contains the experimental implementation developed for the Master's dissertation at UNICAMP.

## Objective

Evaluate the computational overhead introduced by homomorphic encryption in federated learning systems.

## Scenarios

The experiments compare three scenarios:

- Baseline (plaintext aggregation)
- CKKS homomorphic aggregation
- Hybrid approach

## Experimental Setup

- Python
- Scikit-learn
- TenSEAL
- Google Colab

## Results

Preliminary experiments evaluate:

- Latency per federated round
- Model accuracy
- AUC
- F1-score
